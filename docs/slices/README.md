# Slice briefs

One file per slice of the [engineering loop](../loop.md), named `NNNN-<short-name>.md`
and created by the lead from
[`.claude/skills/sacm-slice/references/slice-brief.md`](../../.claude/skills/sacm-slice/references/slice-brief.md).
A brief with `state: in-progress` is resumed by the next `/sacm-slice` run.
